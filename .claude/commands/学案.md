请阅读我指定的章节，作为 [topic] 的老师，为我生成**一个整合文件**：
这一章的完整学案 + 本次 Session 学习记录，全部写进**同一个 .md 文件**。

## 第一步：定位章节

- 如果我在对话里 @ 了章节笔记（如 `章节002-概率.md`），直接以它为准；
- 否则告诉我书名和章节号（如"数理统计第 2 章"），你到 `04-教材分块/<书名>/`
  下找到对应分块。注意：**一章可能被切成多个分块**（文件名以同一个章名开头，
  或大纲里同一章对应多个文件），必须把这一章的全部分块都读完，缺一不可；
- 读完后再对照 `01-全书大纲.md` 或分块 frontmatter 的 `chapter` 字段，
  确认没有漏块。

## 第二步：确定 Session 编号

- 读取主题文件夹（`03-学习主题/<主题名>/`）下所有 `type: session` 的笔记，
  取最大的 `session` 编号 +1 作为本次编号（没有则从 1 开始）；
- 如果存在 `学习计划.md`，尽量对照计划把本次学习对到对应的 Session
  （计划里第几个 Session 就填几）。

## 第三步：生成整合文件（学案 + Session，同一个 .md）

文件名：`学案Session-第X章-<章名>.md`

存放位置：有学习主题 → `03-学习主题/<主题名>/`；还没有主题 →
`04-教材分块/<书名>/`。

frontmatter 按 **session 类型**写（这样首页看板和 `/更新进度` 都能识别）：

```
---
type: session
study_guide: true
topic: <主题名或书名>
session: <本次编号>
date: <今天>
hours: 2
status: 待完成
score:
chapter: <章号>
book: <书名>
focus: <本章主题一句话>
---
```

正文结构（学案在前、Session 记录在后）：

```
# 📘 学案 + Session：第X章 <章名>

## 🎯 本次学习目标
（本章概览：学什么、为什么学、与前后章的关系，3-5 条）

## 🧭 知识结构图
（mermaid 流程图或层级列表）

## 📚 学案：知识点详解
### 知识点 1：<名称>
- 严谨定义/定理/公式（LaTeX，注明适用条件）
- 💡 通俗解释（生活化比喻或直觉）
- 📝 典型例题（含解题思路，不只给答案）
### 知识点 2：<名称>
（……本章有多少知识点就写多少节，必须全部覆盖，一个不漏）

## ⚠️ 常见误区与易错点
- 

## 🧪 自测题（5-8 题，附简要答案或提示）
1. 

## ✅ 本次完成情况
- [ ] 学完本章全部知识点
- [ ] 完成自测题

## 📝 我的笔记
- （学完本章后填写）

## 🤔 卡住的地方 / 问题
- （下次问 AI 的问题写这里）

## 📊 自评
- 掌握度（0-10）：
- 下次要重点补：
```

## 学案内容要求

1. **覆盖全部知识点**：对照本章所有小节标题、定义、定理、公式、例题和案例，
   一个都不许漏；宁可多列，不要省略。
2. **学术严谨**：定义、定理、公式用准确的书面表述，公式用 LaTeX
   （行内 `$...$`、独立行 `$$...$$`），注明适用条件。
3. **通俗易懂**：在严谨表述之后，尽量给每个知识点配生活化的比喻、
   直觉解释或小例子，让我"先懂意思，再记表述"。

## 保存与汇报

- 如果目标文件已存在（比如同一章重做学案），先读旧版，再决定覆盖还是追加，
  不要无提示地覆盖我手写的内容；
- 章节太长（超过约 6 万字）时不要硬塞：分块生成后合并进同一个文件，保证不遗漏；
- 完成后用中文简短汇报：读了几块、覆盖多少个知识点、Session 编号、
  文件链接；并提示我学完后运行 `/更新进度` 自动更新主页进度。

## 注意

- 只读取本章分块和主题主页，不要读整本书或整个库（省钱原则）；
- 如果我在对话里明确说"只要学案"，可以省略 Session 记录部分；
  默认情况下生成上面的整合文件。
