# 🏠 学习工作流首页

> [!tip] 我的学习流程
> **Step 1** 导入教材 → 拆成小分块（AI 一次吃得下）
> **Step 2** AI 把主题拆成 5 个难度级别（找准自己位置）
> **Step 3** AI 制定「二八法则」10 次学习计划（只学最有用的）
> **Step 4** 每学完一块，AI 当考官测试我（找到薄弱点）
> **Step 5** 每次开课前，先看一页速查表（5 分钟复习）

---

## 📚 学习主题总览

```dataview
TABLE topic as 主题, level as 当前级别, progress as 进度(%), status as 状态
FROM "03-学习主题"
WHERE type = "topic"
SORT status ASC, created ASC
```

## 🗓️ 最近的学习记录

```dataview
TABLE date as 日期, topic as 主题, session as 第几次, hours as 时长(小时), score as 掌握度(0-10), status as 状态
FROM "03-学习主题"
WHERE type = "session"
SORT date DESC
LIMIT 15
```

## 📊 各主题平均掌握度

```dataview
TABLE length(rows) as 已完成次数, round(avg(rows.score), 1) as 平均掌握度
FROM "03-学习主题"
WHERE type = "session"
GROUP BY topic
```

> [!info] 开始新主题
> 1. 按 `Ctrl+Shift+N` 新建主题（或 `Ctrl+P` → 「➕ 新建学习主题」）
> 2. 在右侧 Claudian 输入 `/新主题-拆解与计划 <主题名>`，一键生成拆解和计划
> 3. 详细步骤见「📖 使用说明」

> [!note] 怎么让 AI 记住我的进度？
> AI 不会自动记住你 —— **你的笔记就是 AI 的记忆**。
> 每次对话前，打开当前主题的主页笔记并 @ 它，或用 `/更新进度 <主题名>`
> 让 AI 把最近的 Session 进度写回主页。AI 就能读到你的进度、水平和薄弱点。
