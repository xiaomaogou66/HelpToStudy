# 📖 教材分块说明

把厚教材放进来（或放任意位置），然后运行：

```
python "_工具/split_textbook.py" "教材文件路径" --out "04-教材分块"
```

## 最省事的方式：双击启动器

1. 双击 `_工具/拆书.bat`
2. 把教材文件（PDF/EPUB/DOCX）**拖进**弹出的黑色窗口
3. 按回车，等着输出到 `04-教材分块/<书名>/`

> 也可以把一个文件夹拖进去，工具会自动处理里面所有 PDF/EPUB/DOCX。

## 扫描版 PDF（无法提取文字）怎么办？

如果拖入后提示"提取到的文字太少 / 可能是扫描版"，**统一用 MinerU 云端版**：

1. 先双击一次 `_工具/设置MinerU令牌.bat` 保存 Token（免费注册 mineru.net）
2. 双击 `_工具/拆书-MinerU.bat`，把扫描版教材拖进窗口，按回车
3. MinerU 云端解析（公式转 LaTeX），再按章节拆成一章一个文件

> 提示：750 页的书大约需要 20-40 分钟；每日免费 1000 页。

例如：

```
python "_工具/split_textbook.py" "D:\Downloads\Python入门教材.pdf" --out "04-教材分块"
```

支持格式：**PDF、EPUB、Word (.docx)**。

## 常用参数

| 参数 | 作用 | 默认 |
| --- | --- | --- |
| `--out` | 输出文件夹 | 当前目录的 `教材分块` |
| `--max-chars` | 已停用：一章一个文件，不再按字数切块 | — |
| `--overlap` | 相邻块重叠字符数（防止切断关键句） | 200 |

## 输出结构

```
04-教材分块/
└── <书名>/
    ├── 00-教材信息.md      ← 全书信息、总字数
    ├── 00-目录.md          ← 所有分块清单
    ├── 01-全书大纲.md       ← 章节大纲 + 进度勾选清单
    ├── 章节01-第1章 概述.md
    ├── 章节02-第2章 ....md
    └── ...
```

然后：

- 在 Claudian 输入 `/拆书` 可让 AI 汇报章节清单；
- 打开 `01-全书大纲.md` 查看全书骨架、勾选学习进度；
- 用 `/新主题-拆解与计划 <主题名>` 基于大纲生成水平拆解和学习计划；
- 学完一章后运行 `/更新进度` 自动勾选。

> 说明：默认**按章节拆分，一章一个文件**，章节内部不再切分，
> 公式不会因截断显示错误；识别不到章节时全书存为一个文件并提示校准。
